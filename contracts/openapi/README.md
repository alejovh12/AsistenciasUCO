# Ubicación histórica del contrato HTTP

La fuente canónica del Golden Path se encuentra en
[`docs/contracts/openapi/openapi-golden-path.yaml`](../../docs/contracts/openapi/openapi-golden-path.yaml),
con su SHA-256 adyacente. Esta carpeta se conserva como redirección para enlaces históricos; no
debe recibir una copia paralela del YAML.

Seguir [OPENAPI_STANDARD](../../docs/contracts/OPENAPI_STANDARD.md),
[API_DESIGN_RULES](../../docs/governance/API_DESIGN_RULES.md) y la
[matriz HTTP AS-IS](../../docs/contracts/HTTP_AS_IS_MATRIX.md). OpenAPI YAML, no annotations Java,
es la fuente del contrato cubierto.

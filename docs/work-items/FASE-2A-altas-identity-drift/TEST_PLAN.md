## Reglas de ejecución y evidencia

- Las pruebas interactivas se ejecutan solo en el navegador integrado. No autenticar hasta que el usuario lo haga manualmente en esa sesión; nunca pedir contraseña por chat.
- Una validación que pueda persistir una cuenta/vínculo requiere fixture aprobado y procedimiento verificado de identificación y limpieza. Sin él: `NOT_RUN`, sin POST válido.
- En evidencia usar datos sintéticos saneados; registrar request method/path/status/código/correlation ID y no guardar raw logs, credenciales, cookies, JWT o PII.
- Java 25. Unit/contract sin dependencias externas son ejecutables por Maven; integración SQL/IdP requiere preflight y destino controlado. Las pruebas en tests no sustituyen la evidencia de UI.
